Import assessment data

Drop a CSV and every page redraws from it. Nothing leaves this device.

Drop a CSV here

Rows are checked against the scoring rules before anything loads.

Expected columns

yearAssessment year.
quarterQ1 to Q4. Month 1 to 3 are derived from this.
lgaLocal government name. Blank rows are held.
wardWard the facility sits in.
facilityFacility name as on the master list.
levelPrimary, Secondary or Tertiary.
ownerPublic or Private.
start_date, end_dateAssessment visit dates.
availability_m1 … m3Score out of 100 for each month.
consistency_m1 … m3Score out of 100 for each month.
validity_m1 … m3Score out of 100 for each month.

Overall is never imported. It is always recalculated as the mean of the nine scores, so a stored overall can never drift from its parts.

Data issues

Checks that run on every import. Rows failing a hard rule never reach the dashboard, so a broken row can no longer render as a chart.

Each check exists because a real report can fail this way: a score above 100 means a total was written into a per-month column, a ward reading "Quarterly" means the columns shifted by one, and a facility name that parses as a number means a header row was ingested as data.
